### الفكرة
حزمة نموذج نجمي للمبيعات مع بيانات عينة ومقاييس DAX ودليل بناء التقرير.

### التقنيات
Power BI, DAX, Excel/CSV

### المميزات
- Star schema
- مقاييس Revenue/YTD
- بيانات جاهزة للاستيراد

### طريقة التشغيل
1. افتح Power BI Desktop
2. استورد ملفات data/*.csv
3. طبّق العلاقات والمقاييس من docs/ و dax/
